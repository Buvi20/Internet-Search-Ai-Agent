# AI Research Assistant

## Overview

An AI research assistant built with n8n, OpenAI, and Tavily Search. The workflow retrieves relevant information and uses AI to help summarize research findings.

## Tools Used

* n8n for workflow automation
* OpenAI for AI-powered processing
* Tavily Search for web research

## Purpose

This project demonstrates my practical experience building AI agents that connect language models with external tools to support research and information retrieval.

## Security

Credentials and API keys should be configured securely and are not included in this public project.
